## सुविधाएँ

- ⌨️ **पैनल के लिए एक शॉर्टकट**: `Alt+B` (Mac पर `⌥B`) पैनल खोलता है, पेज से फ़ोकस वापस लाता है और पैनल बंद करता है।
  इसे `chrome://extensions/shortcuts` में बदला जा सकता है।
- 📌 **बुकमार्क पिन किए गए टैब की तरह**, Arc की तरह: जिस बुकमार्क का टैब खुला है उस पर एक बिंदु (और समेटे गए फ़ोल्डर पर एक छल्ला,
  अगर उसके अंदर कुछ खुला है)। बुकमार्क दोबारा खोलने पर उसके टैब पर स्विच होता है, `Shift+Enter` टैब को बुकमार्क के पते पर
  लौटाता है, `U` मौजूदा पता बुकमार्क में सहेजता है। यह मोड सेटिंग में बंद किया जा सकता है।
- 🔎 **खोज**: `/` या `⌘F`/`Ctrl+F`, शीर्षक, पते और फ़ोल्डर से, हाइलाइट के साथ। `Tab` मिला हुआ आइटम ट्री में उसकी जगह पर
  दिखाता है।
- 🗂️ **बुकमार्क छाँटें**: निशान (`स्पेस`, `Shift+↑↓`, `⌘A`), नाम से फ़ोल्डर में ले जाना (`M`, हाल के फ़ोल्डर ऊपर; फ़ोल्डर न हो तो
  बन जाता है), सूची में ऊपर-नीचे ले जाना (`Alt+↑↓`), नया फ़ोल्डर (`N`), नाम बदलना (`R`), हटाना (`D`), पते कॉपी करना (`C`)।
- ↩️ **पहले जैसा करें और फिर से करें** (2.6 में नया): Mac पर `⌘Z` / `⌘⇧Z`, बाकी में `Ctrl+Z` और `Ctrl+Shift+Z` या `Ctrl+Y`,
  या संदेश में “पहले जैसा करें” बटन। हटाया गया फ़ोल्डर अपनी सामग्री के साथ लौट आता है। इतिहास में 50 चरण रहते हैं और ब्राउज़र
  बंद होने तक वह सभी विंडो में साझा रहता है।
- 🖱️ **खींचें और छोड़ें** (2.6 में नया): बुकमार्क, फ़ोल्डर और निशान लगे आइटम को माउस से ऊपर, नीचे या फ़ोल्डर के अंदर खींचा जा
  सकता है। आइटम को फ़ोल्डर पर रोकने से फ़ोल्डर खुल जाता है, और किनारे के पास सूची स्क्रोल होती है।
- 📋 **दायाँ-क्लिक मेन्यू** (2.6 में नया), ब्राउज़र के बुकमार्क मेन्यू जैसा: नए टैब, नई विंडो, स्प्लिट व्यू या गुप्त विंडो में
  खोलें; संपादित करें; काटें, कॉपी करें और चिपकाएं; हटाएं; पृष्ठ या फ़ोल्डर जोड़ें; बुकमार्क मैनेजर खोलें। कीबोर्ड से:
  `Shift+F10`।
- 📂 **सेट के रूप में खोलें**: निशान लगे बुकमार्क या पूरा फ़ोल्डर, नाम वाले टैब ग्रुप के रूप में या सामान्य टैब के रूप में। पहले से
  खुले टैब दोबारा नहीं खुलते।
- 🎛️ **कमांड पैलेट**: `⌘K`/`Ctrl+K` या `?` — सभी कमांड उनकी कुंजियों के साथ।
- 🔧 **आपकी अपनी कुंजियाँ**: किसी भी कमांड की कुंजियाँ सेटिंग में बदली जा सकती हैं। Vim प्रीसेट, क्रम (`G G`) और दो बार दबाना भी
  है। कुंजियाँ अपनी जगह से पहचानी जाती हैं, इसलिए किसी भी कीबोर्ड लेआउट पर काम करती हैं।
- 👁️ **दृश्य**: `V` सामान्य, पते के साथ (शीर्षक के नीचे साइट) और सघन दृश्य के बीच बदलता है।
- ⚙️ **सेटिंग**: शुरुआती फ़ोल्डर, बुकमार्क नए टैब में खोलें, बुकमार्क को पिन किए गए टैब की तरह, फ़ोकस पेज पर जाने पर पैनल बंद
  करें।
- 🌍 **10 भाषाएँ**, दाएँ से बाएँ लिखी जाने वाली भाषाओं के समर्थन के साथ; अंदर की सहायता (`i`) हर तरीका समझाती है।

## इंस्टॉल करना

**GitHub Release से**

1. [नवीनतम रिलीज़](https://github.com/Airnook/bookmarks/releases/latest) से `airnook-bookmarks-<वर्ज़न>.zip` डाउनलोड करें।
2. आर्काइव को किसी स्थायी फ़ोल्डर में अनपैक करें: ब्राउज़र एक्सटेंशन को वहीं से पढ़ता है।
3. `chrome://extensions` खोलें और “डेवलपर मोड” चालू करें।
4. “अनपैक किया गया लोड करें” दबाएँ और `manifest.json` वाला फ़ोल्डर चुनें।
5. अपडेट करने के लिए उसी फ़ोल्डर में फ़ाइलें बदलें और एक्सटेंशन के कार्ड पर “फिर से लोड करें” दबाएँ।

**Chrome Web Store**: जल्द आ रहा है।

Chromium 141 या नया वर्ज़न ज़रूरी है।

## शुरुआत कैसे करें

1. `Alt+B` — पैनल खोलें। फिर से दबाने पर बंद होता है; अगर फ़ोकस पेज पर चला गया हो, तो वही शॉर्टकट उसे पैनल में वापस लाता है।
   एक्सटेंशन का आइकन भी पैनल खोलता है — उसे ब्राउज़र के एक्सटेंशन मेन्यू में पिन करें।
2. `↑` `↓` — सूची में चलें, `→` `←` — फ़ोल्डर फैलाएँ और समेटें, `Enter` — खोलें।
3. `/` — खोज: शीर्षक, साइट या फ़ोल्डर टाइप करना शुरू करें।
4. `स्पेस` — कई बुकमार्क पर निशान लगाएँ, `M` — उन्हें नाम से फ़ोल्डर में ले जाएँ।
5. `⌘K`/`Ctrl+K` — कमांड पैलेट: सभी कमांड उनकी कुंजियों के साथ।
6. बुकमार्क, फ़ोल्डर या खाली जगह पर दायाँ बटन — ब्राउज़र जैसा मेन्यू; `Shift+F10` — वही कीबोर्ड से।
7. `i` — सहायता। नए बुकमार्क ब्राउज़र के सामान्य तरीके से जुड़ते हैं — `⌘D`/`Ctrl+D`।

## डिफ़ॉल्ट कुंजियाँ

Windows और Linux पर `⌘` का मतलब `Ctrl` है। कोई भी कुंजी सेटिंग में बदली जा सकती है।

| क्रिया | कुंजियाँ |
| --- | --- |
| सूची में चलें / फ़ोल्डर फैलाएँ, समेटें | `↑` `↓` / `→` `←`, `Home` `End` |
| खोलें / दूसरे टैब में खोलें | `Enter` / `⌘Enter` |
| टैब को बुकमार्क के पते पर लौटाएँ | `Shift+Enter` |
| बुकमार्क खोजें | `/`, `⌘F` |
| कमांड पैलेट | `⌘K`, `?` |
| मेन्यू खोलें | `Shift+F10` |
| निशान लगाएँ / लगातार / फ़ोल्डर में सब पर निशान लगाएँ | `स्पेस` / `Shift+↑↓` / `⌘A` |
| फ़ोल्डर में ले जाएँ… / ऊपर, नीचे ले जाएँ | `M` / `Alt+↑↓` |
| नया फ़ोल्डर, नाम बदलें, हटाएँ | `N`, `R` (`F2`), `D` |
| पता कॉपी करें / टैब का पता सहेजें | `C` / `U` |
| काटें, कॉपी करें, चिपकाएं | `⌘X`, `⌘C`, `⌘V` |
| पहले जैसा करें / फिर से करें | `⌘Z` / `⌘⇧Z`, `⌘Y` |
| बुकमार्क का टैब बंद करें | `⌫`, `Delete` |
| दृश्य बदलें / सहायता / सेटिंग | `V` / `i` (`F1`) / `,` |
| रद्द करें या बंद करें: निशान हटाएँ, खोज से निकलें, पैनल बंद करें | `Esc` |

## निजता

एक्सटेंशन सिर्फ़ स्थानीय रूप से काम करता है और नेटवर्क पर कुछ नहीं भेजता: न आपके बुकमार्क और न आपका इतिहास ब्राउज़र से बाहर जाता
है। सेटिंग ब्राउज़र में एक्सटेंशन के लोकल स्टोरेज में रहती हैं। अनुमतियाँ बुकमार्क, साइड पैनल, साइट आइकन, टैब और टैब ग्रुप
(पिन किए गए टैब का मोड और सेट खोलना) और सेटिंग सहेजने के लिए चाहिए।

## डेवलपमेंट

बिना बिल्ड के सादा JavaScript (Manifest V3): ब्राउज़र रिपॉज़िटरी की रूट से फ़ाइलें जैसी हैं वैसी ही लोड करता है।

```sh
npm ci
npm run lint
npm test
npm run test:browser   # Chromium में स्मोक टेस्ट: npx playwright install chromium
npm run package        # dist/airnook-bookmarks-<वर्ज़न>.zip
```

आर्किटेक्चर, टेस्ट और रिलीज़ की प्रक्रिया [CONTRIBUTING.md](CONTRIBUTING.md) में बताई गई है।
