**Закладки** — расширение для Chromium-браузеров (Chrome, Edge, Brave, Arc, Helium и другие): ваши закладки в боковой
панели, сбоку от страницы, и всё — с клавиатуры. Найти, открыть, разложить по папкам, держать закладки как закреплённые
вкладки. Сделано при переезде с Arc на Chromium-браузер: не хватало его боковой панели.

## Возможности

- ⌨️ **Одна клавиша для панели**: `Alt+B` (на Mac `⌥B`) открывает панель, возвращает фокус со страницы и закрывает её.
  Сочетание меняется в `chrome://extensions/shortcuts`.
- 📌 **Закладки как закреплённые вкладки**, как в Arc: точка у закладок с открытой вкладкой (и кольцо у свёрнутой
  папки, где что-то открыто). Повторное открытие переключает на вкладку закладки, `Shift+Enter` возвращает вкладку на
  адрес закладки, `U` запоминает в закладке текущий адрес. Режим выключается в настройках.
- 🔎 **Поиск**: `/` или `⌘F`/`Ctrl+F`, по названию, адресу и папке, с подсветкой. `Tab` показывает найденное на месте
  в дереве.
- 🗂️ **Разбор закладок**: отметки (`Пробел`, `Shift+↑↓`, `⌘A`), перемещение в папку по имени (`M`, недавние папки
  сверху, нет такой папки — создаст), перемещение по списку (`Alt+↑↓`), новая папка (`N`), переименование (`R`),
  удаление (`D`), копирование адресов (`C`).
- ↩️ **Отмена и повтор** (новое в 2.6): `⌘Z` / `⌘⇧Z` на Mac, `Ctrl+Z` и `Ctrl+Shift+Z` или `Ctrl+Y` в остальных
  системах, либо кнопка «Отменить» в сообщении. Удалённая папка возвращается вместе с содержимым. В истории 50 шагов,
  она общая для всех окон до закрытия браузера.
- 🖱️ **Перетаскивание** (новое в 2.6): закладки, папки и отмеченное можно перетаскивать мышью выше, ниже или внутрь
  папки. Папка раскрывается, если задержать над ней элемент, а список прокручивается у края.
- 📋 **Меню правой кнопкой** (новое в 2.6) — как меню закладок браузера: открыть в новой вкладке, новом окне, режиме
  разделения экрана или режиме инкогнито; изменить; вырезать, копировать и вставить; удалить; добавить страницу или
  папку; открыть менеджер закладок. С клавиатуры — `Shift+F10`.
- 📂 **Открыть набором**: отмеченное или папку целиком — группой вкладок с названием или обычными вкладками. Уже
  открытые вкладки не дублируются.
- 🎛️ **Палитра команд**: `⌘K`/`Ctrl+K` или `?` — все команды с их клавишами.
- 🔧 **Свои клавиши**: любую команду можно переназначить в настройках. Есть набор Vim, последовательности (`G G`) и
  двойные нажатия. Клавиши сравниваются по положению, поэтому работают на любой раскладке.
- 👁️ **Вид**: `V` переключает обычный вид, вид с адресом под названием и компактный.
- ⚙️ **Настройки**: стартовая папка, открывать закладки в новой вкладке, закладки как закреплённые вкладки, закрывать
  панель, когда фокус уходит на страницу.
- 🌍 **10 языков** с поддержкой письма справа налево; встроенная справка (`i`) описывает все сценарии.

## Установка

**Из GitHub Release**

1. Скачайте `airnook-bookmarks-<версия>.zip` из [последнего релиза](https://github.com/Airnook/bookmarks/releases/latest).
2. Распакуйте архив в постоянную папку: браузер читает расширение оттуда.
3. Откройте `chrome://extensions` и включите «Режим разработчика».
4. Нажмите «Загрузить распакованное» и выберите папку с `manifest.json`.
5. Обновление: замените файлы в той же папке и нажмите «Обновить» на карточке расширения.

**Chrome Web Store**: скоро.

Нужен Chromium 141 или новее.

## Быстрый старт

1. `Alt+B` — открыть панель. Нажмите ещё раз, чтобы закрыть; если фокус ушёл на страницу, то же сочетание вернёт его
   в панель. Панель открывает и значок расширения — закрепите его в меню расширений браузера.
2. `↑` `↓` — по списку, `→` `←` — раскрыть и свернуть папку, `Enter` — открыть.
3. `/` — поиск: начните печатать название, сайт или папку.
4. `Пробел` — отметить несколько закладок, `M` — переместить их в папку по имени.
5. `⌘K`/`Ctrl+K` — палитра команд: все команды с их клавишами.
6. Правая кнопка на закладке, папке или пустом месте — меню как в браузере; `Shift+F10` — то же с клавиатуры.
7. `i` — справка. Новые закладки добавляются как обычно в браузере — `⌘D`/`Ctrl+D`.

## Клавиши по умолчанию

`⌘` — это `Ctrl` в Windows и Linux. Любую клавишу можно сменить в настройках.

| Действие | Клавиши |
| --- | --- |
| По списку / раскрыть, свернуть папку | `↑` `↓` / `→` `←`, `Home` `End` |
| Открыть / открыть в другой вкладке | `Enter` / `⌘Enter` |
| Вернуть вкладку на адрес закладки | `Shift+Enter` |
| Поиск закладок | `/`, `⌘F` |
| Палитра команд | `⌘K`, `?` |
| Открыть меню | `Shift+F10` |
| Отметить / подряд / отметить всё в папке | `Пробел` / `Shift+↑↓` / `⌘A` |
| Переместить в папку… / переместить вверх, вниз | `M` / `Alt+↑↓` |
| Новая папка, переименовать, удалить | `N`, `R` (`F2`), `D` |
| Копировать адрес / запомнить адрес вкладки | `C` / `U` |
| Вырезать, копировать, вставить | `⌘X`, `⌘C`, `⌘V` |
| Отменить / повторить | `⌘Z` / `⌘⇧Z`, `⌘Y` |
| Закрыть вкладку закладки | `⌫`, `Delete` |
| Сменить вид / справка / настройки | `V` / `i` (`F1`) / `,` |
| Отменить или закрыть: снять отметки, выйти из поиска, закрыть панель | `Esc` |

## Приватность

Расширение работает только локально и ничего не отправляет в сеть: ни закладки, ни история не покидают браузер.
Настройки хранятся в локальном хранилище расширения в браузере. Разрешения нужны для закладок, боковой панели, иконок
сайтов, вкладок и групп вкладок (режим закреплённых вкладок и открытие наборов) и хранения настроек.

## Разработка

Чистый JavaScript (Manifest V3) без сборки: браузер загружает файлы из корня репозитория как есть.

```sh
npm ci
npm run lint
npm test
npm run test:browser   # смоук-тест в Chromium: npx playwright install chromium
npm run package        # dist/airnook-bookmarks-<версия>.zip
```

Устройство кода, тесты и выпуск релиза описаны в [CONTRIBUTING.md](CONTRIBUTING.md).
