**الإشارات المرجعية** إضافة لمتصفّحات Chromium ‏(Chrome وEdge وBrave وArc وHelium وغيرها): إشاراتك المرجعية في اللوحة
الجانبية بجانب الصفحة، وكل شيء من لوحة المفاتيح. البحث والفتح والفرز في مجلدات والإبقاء على الإشارات المرجعية كعلامات
تبويب مثبّتة. صُنعت عند الانتقال من Arc إلى متصفّح Chromium، إذ افتقدنا لوحته الجانبية.

## الميزات

- ⌨️ **اختصار واحد للوحة**: ‏`Alt+B` (‏`⌥B` على Mac) يفتح اللوحة، ويعيد التركيز إليها من الصفحة، ويغلقها. يمكن تغييره في
  ‏`chrome://extensions/shortcuts`.
- 📌 **الإشارات المرجعية كعلامات تبويب مثبّتة**، كما في Arc: نقطة على الإشارة المرجعية التي لها علامة تبويب مفتوحة (وحلقة على
  مجلد مطويّ فيه شيء مفتوح). فتح الإشارة المرجعية مرة أخرى ينتقل إلى علامة تبويبها، و‏`Shift+Enter` يعيد علامة التبويب إلى
  عنوان URL للإشارة المرجعية، و‏`U` يحفظ عنوان URL الحالي في الإشارة المرجعية. يمكن إيقاف هذا الوضع في الإعدادات.
- 🔎 **البحث**: ‏`/` أو ‏`⌘F`/`Ctrl+F`، بالعنوان وعنوان URL والمجلد، مع التمييز. ‏`Tab` يُظهر النتيجة في موضعها في الشجرة.
- 🗂️ **فرز الإشارات المرجعية**: التحديد (‏`المسافة`، ‏`Shift+↑↓`، ‏`⌘A`)، والنقل إلى مجلد بالاسم (‏`M`، المجلدات الأخيرة أولًا،
  وإن لم يوجد المجلد يُنشأ)، والنقل في القائمة (‏`Alt+↑↓`)، ومجلد جديد (‏`N`)، وإعادة التسمية (‏`R`)، والحذف (‏`D`)، ونسخ
  عناوين URL ‏(`C`).
- ↩️ **التراجع والإعادة** (جديد في 2.6): ‏`⌘Z` / ‏`⌘⇧Z` على Mac، و‏`Ctrl+Z` و‏`Ctrl+Shift+Z` أو ‏`Ctrl+Y` في بقية الأنظمة،
  أو زر «تراجع» في الرسالة. يعود المجلد المحذوف مع محتوياته. يحفظ السجل 50 خطوة ويُشارَك بين كل النوافذ حتى إغلاق المتصفح.
- 🖱️ **السحب والإفلات** (جديد في 2.6): اسحب بالماوس الإشارات المرجعية والمجلدات والعناصر المحدَّدة فوق عنصر أو تحته أو داخل
  مجلد. يُفتح المجلد عند إبقاء عنصر فوقه، وتتمرّر القائمة قرب الحافة.
- 📋 **قائمة الزر الأيمن** (جديد في 2.6)، مثل قائمة الإشارات المرجعية في المتصفح: الفتح في علامة تبويب جديدة أو نافذة جديدة
  أو وضع «تقسيم العرض» أو نافذة التصفُّح المتخفي؛ التعديل؛ القص والنسخ واللصق؛ الحذف؛ إضافة صفحة أو مجلد؛ فتح «مدير الإشارات».
  من لوحة المفاتيح: ‏`Shift+F10`.
- 📂 **الفتح كمجموعة**: الإشارات المرجعية المحدَّدة أو مجلد كامل، كمجموعة علامات تبويب باسم أو كعلامات تبويب عادية. لا تُفتح
  علامات التبويب المفتوحة مسبقًا مرة ثانية.
- 🎛️ **لوحة الأوامر**: ‏`⌘K`/`Ctrl+K` أو ‏`?` — كل الأوامر مع مفاتيحها.
- 🔧 **مفاتيحك الخاصة**: يمكن تغيير مفاتيح أي أمر في الإعدادات. تتوفر مجموعة Vim، والتسلسلات (‏`G G`)، والضغط المزدوج.
  تُطابَق المفاتيح بحسب موضعها، لذلك تعمل على أي تخطيط للوحة المفاتيح.
- 👁️ **العرض**: ‏`V` يبدّل بين العادي، ومع عنوان URL أسفل العنوان، والمضغوط.
- ⚙️ **الإعدادات**: مجلد البداية، وفتح الإشارات المرجعية في علامة تبويب جديدة، والإشارات المرجعية كعلامات تبويب مثبّتة،
  وإغلاق اللوحة عند انتقال التركيز إلى الصفحة.
- 🌍 **10 لغات** مع دعم الكتابة من اليمين إلى اليسار؛ والمساعدة المدمجة (‏`i`) تشرح كل طرق الاستخدام.

## التثبيت

**من GitHub Release**

1. نزّل ‏`airnook-bookmarks-<الإصدار>.zip` من [أحدث إصدار](https://github.com/Airnook/bookmarks/releases/latest).
2. فُكّ ضغط الأرشيف في مجلد دائم: يقرأ المتصفح الإضافة من هناك.
3. افتح ‏`chrome://extensions` وفعّل «وضع مطوّر البرامج».
4. انقر «تحميل الإضافة غير المضغوطة» واختر المجلد الذي فيه ‏`manifest.json`.
5. للتحديث، استبدل الملفات في المجلد نفسه وانقر «إعادة التحميل» على بطاقة الإضافة.

**Chrome Web Store**: قريبًا.

يلزم Chromium 141 أو أحدث.

## البدء السريع

1. ‏`Alt+B` — فتح اللوحة. اضغط مرة أخرى لإغلاقها؛ وإذا انتقل التركيز إلى الصفحة فإن الاختصار نفسه يعيده إلى اللوحة. تفتح
   أيقونة الإضافة اللوحة أيضًا — ثبّتها في قائمة إضافات المتصفّح.
2. ‏`↑` ‏`↓` — التنقل في القائمة، ‏`←` ‏`→` — توسيع المجلد وطيّه، ‏`Enter` — فتح.
3. ‏`/` — بحث: ابدأ بكتابة عنوان أو موقع أو مجلد.
4. ‏`المسافة` — تحديد عدة إشارات مرجعية، ‏`M` — نقلها إلى مجلد بالاسم.
5. ‏`⌘K`/`Ctrl+K` — لوحة الأوامر: كل الأوامر مع مفاتيحها.
6. الزر الأيمن على إشارة مرجعية أو مجلد أو مكان فارغ — قائمة مثل قائمة المتصفح؛ ‏`Shift+F10` — الشيء نفسه من لوحة المفاتيح.
7. ‏`i` — المساعدة. تُضاف الإشارات المرجعية الجديدة بالطريقة المعتادة في المتصفّح — ‏`⌘D`/`Ctrl+D`.

في اللغات التي تُكتب من اليمين إلى اليسار يتبادل السهمان ‏`←` و‏`→` موضعيهما: ‏`←` يوسّع المجلد، و‏`→` يطويه.

## المفاتيح الافتراضية

‏`⌘` هو ‏`Ctrl` في Windows وLinux. يمكن تغيير أي مفتاح في الإعدادات.

| الإجراء | المفاتيح |
| --- | --- |
| التنقل في القائمة / توسيع المجلد، طيّ المجلد | `↑` `↓` / `←` `→`، `Home` `End` |
| فتح / فتح في علامة تبويب أخرى | `Enter` / `⌘Enter` |
| إعادة علامة التبويب إلى عنوان URL للإشارة المرجعية | `Shift+Enter` |
| البحث في الإشارات المرجعية | `/`، `⌘F` |
| لوحة الأوامر | `⌘K`، `?` |
| فتح القائمة | `Shift+F10` |
| تحديد / تحديد متتالٍ / تحديد كل ما في المجلد | `المسافة` / `Shift+↑↓` / `⌘A` |
| نقل إلى مجلد… / نقل لأعلى، لأسفل | `M` / `Alt+↑↓` |
| مجلد جديد، إعادة تسمية، حذف | `N`، `R` ‏(`F2`)، `D` |
| نسخ عنوان URL / حفظ عنوان URL لعلامة التبويب | `C` / `U` |
| قص، نسخ، لصق | `⌘X`، `⌘C`، `⌘V` |
| تراجع / إعادة | `⌘Z` / `⌘⇧Z`، `⌘Y` |
| إغلاق علامة تبويب الإشارة المرجعية | `⌫`، `Delete` |
| تغيير العرض / مساعدة / الإعدادات | `V` / `i` ‏(`F1`) / `,` |
| إلغاء أو إغلاق: إزالة التحديد، الخروج من البحث، إغلاق اللوحة | `Esc` |

## الخصوصية

تعمل الإضافة محليًا فقط ولا ترسل أي شيء عبر الشبكة: لا تغادر إشاراتك المرجعية ولا سجلّك المتصفح. تُحفظ الإعدادات في
التخزين المحلي للإضافة داخل المتصفح. الأذونات مطلوبة للإشارات المرجعية، واللوحة الجانبية، وأيقونات المواقع، وعلامات التبويب
ومجموعاتها (وضع علامات التبويب المثبّتة والفتح كمجموعة)، ولحفظ الإعدادات.

npm run lint

npm run package        # dist/airnook-bookmarks-<version>.zip
